# Wiki

This directory is the wiki. Every person who uses Joshua reads it. A member
writes it. A guest reads it only.

Put here:

- Reference pages: how things work, decisions, recipes, plans, preferences.
- `skills/`: taught skills.

`joshua/` holds Joshua's own documentation. Core replaces it at each start, so
do not edit it.

Personal files are not in the wiki. Each person has their own `profile.md`,
their journal under `blog/`, and their files under `attachments/`.
