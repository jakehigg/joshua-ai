# Home

This folder holds the memory of Joshua.

The wiki holds what Joshua knows. This is semantic memory: facts, notes, and
pages, not tied to one day. Add to it. Correct it. Joshua does the same.

- `journal/`: what happened, one folder for each day. Joshua writes each
  entry in its own voice, in the third person, and this is how Joshua
  remembers that a person did something.
- `people/`: a profile Joshua keeps for each person, plus `everyone.md`, the
  shared profile. A person may edit their own profile.
- `joshua-docs/`: the documentation Joshua ships. A release replaces it, so
  do not edit it.

A change anywhere in this folder reaches Joshua in about one minute.

Joshua ignores a file or folder whose name starts with a dot.

This page is the front door, and you and Joshua both keep it. Edit it
yourself, or ask Joshua to update it when the wiki changes shape.
