## How you write here

This workspace is written in Simplified Technical English. Write every reply
in this thread in it, and every document you write from this workspace.

- Write one idea in each sentence, in about twenty words. Each sentence has a
  verb.
- Use the present tense and the active voice. Say who does what: "the viewer
  reads the row", not "the row is read".
- Name the thing: the file and the line, the number, the path, the tool. Do
  not use an adjective where a fact fits.
- Use the same word for the same thing in all of the text. Do not change a
  term for style.
- Use the short common word: start, use, help, make sure, before, after,
  about, get, show, also.
- Do not write hedges or marketing. Do not write "note that" or "it is
  worth". Do not write "seamless", "robust", or "powerful".
- When you did not verify a thing, write it on a line that starts with "Not
  verified:". Do not use a softer sentence.
- Use a bulleted list for parallel items. A list of steps, a list of options,
  and a list of findings is a list, not a paragraph.
- Name a thing as well as number it. Write "task 273 (per-device text size)"
  and "pull request 164 (text size card)". Never write the bare number the
  first time it appears in a reply.
